# 1688 批发采购与数据对账系统 (`1688-ops`)

基于浏览器已认证原生会话的 1688 货源检索、拍立淘搜款、阶梯批发价提取、采购车同步、订单拉取、供货智能推理决策与离线数据真理库工具套件。

---

## 核心设计准则

1. **合力造轮子，严禁碎片化**：
   - 适配器唯一源码归属：`~/Documents/A-coding/opencli-fork/clis/1688`。
   - 运行态热部署路径：`~/.opencli/clis/1688`。
   - 严禁在调用方散落临时抓取脚本；所有改动通过 `adapter_contract.test.js` 执行哈希一致性校验。
2. **单一事实来源**：
   - 本地 SQLite (`data/1688_ops.db`) 作为终态真理库。
   - 所有在线抓取的商品、采购车与订单数据统一收敛入库，离线可秒级查询与多维排序。
3. **单向数据流**：
   - 读流向：数据库 -> 数据访问层 -> 终端界面展示。
   - 写流向：浏览器抓取 -> 纯函数清洗与派生计算 -> 写入数据库 -> 重新查询渲染。
4. **能派生不另存**：
   - 销量整数与回头率百分比在解析阶段由原始展示文本即时派生，原始凭据与计算结果并存。
5. **可观测性与对账器优先**：
   - 能读：读取当前环境配置、数据库统计与 10 个适配器的 SHA-256 同步状态。
   - 能试：使用真实生产解析函数对脏数据样本进行白盒推导对账。
   - 能调：支持从适配器源码一键热同步至 OpenCLI 运行区。

## 系统架构与全景图谱

系统采用原生 ESM 模块化架构，实现零外部 NPM 依赖，底层调用原生 `node:sqlite`、`node:test` 与 `node:child_process`。

```
+===================================================================================+
|                                1. 接入与调度层                                     |
+===================================================================================+
| 终端命令行: 1688-ops / 1688-cli                                                   |
| 编程客户端: HubClient1688 (进程调度、超时看门狗 75s、异常捕获与容错)               |
+===================================================================================+
                                      |
                                      v
+===================================================================================+
|                           2. 适配器与数据采集层                                   |
+===================================================================================+
| 源码真理库: opencli-fork/clis/1688 <---> 运行区: ~/.opencli/clis/1688 (双向防漂移) |
| 采集适配器: search / image-search / item / store / cart / orders                  |
| 分页与去重: search 与 orders 跨页自动化拉取 (--pages)                              |
| 认证与会话: 复用已登录原生 Chrome 会话 Cookie 与凭据                               |
+===================================================================================+
                                      |
                                      v
+===================================================================================+
|                          3. 纯函数解析与智能推理层                                |
+===================================================================================+
| 数据清洗: extractor.js (价格区间、销量万级换算、起订量、回头率百分比派生)         |
| 供货推理: reasoner.js (供应商量化评分、阶梯降价分解、毛利测算、7项风控排查)        |
+===================================================================================+
                                      |
                                      v
+===================================================================================+
|                         4. 单一事实真理持久化层                                   |
+===================================================================================+
| 数据访问层: db.js (基于 node:sqlite DatabaseSync, WAL 模式, 外键开启)              |
| 核心真理表: offers (商品真理) / cart_items (采购车) / orders (采购历史流水)       |
+===================================================================================+
                                      |
                                      v
+===================================================================================+
|                         5. 可观测与自治运维层                                     |
+===================================================================================+
| 对账诊断器: diagnose.js (能读环境状态 / 能试生产样本 / 能调热同步)                 |
| 契约测试集: adapter_contract.test.js (SHA-256 零漂移保证)                         |
+===================================================================================+
```

## 常用命令说明

### 1. 登录态与环境诊断
```bash
# 检查 1688 登录态与操作者身份
1688-ops doctor

# 输出当前登录账号结构化数据
1688-ops whoami
```

### 2. 货源检索与以图搜款
```bash
# 关键词检索货源并自动入库（支持指定数量与分页）
1688-ops search "折叠椅" --limit 20 --pages 2

# 纯在线查询不写入离线库
1688-ops search "户外帐篷" --limit 10 --no-sync

# 拍立淘以图搜款
1688-ops image-search /path/to/sample.jpg --limit 10
```

### 3. 商品详情与店铺查询
```bash
# 抓取指定商品详细信息（含多图清单、起订量、服务保障）
1688-ops item 1024786474053

# 查询供应商店铺档案与经营资质
1688-ops store shop751a009v46r94
```

### 4. 采购车与采购订单
```bash
# 拉取当前买家采购车并同步入库
1688-ops cart

# 拉取采购订单流水并同步入库（支持分页）
1688-ops orders --pages 2
```

### 5. 供货智能推理与决策分析 (Reasoner)
```bash
# 对指定货源执行全维供货推理与风险排查
1688-ops reason 1024786474053

# 输入预期销售价格与币种，测算跨境到仓成本、毛利空间与保本广告 ROAS
1688-ops reason 1024786474053 --target-price 34.99 --currency USD

# 强制在线刷新商品最新数据并输出结构化 JSON (供自动化 Agent 流水线直接消费)
1688-ops reason 1024786474053 --live --json
```

核心推理维度说明：
- **供应商可信度打分 (0-100)**：综合复购/回头率 (30%)、商家工厂与验厂资质 (25%)、动销销量 (20%)、履约发货时效 (15%) 与价格稳定性 (10%)。
- **阶梯价格与起订量分解**：拆解多档起订区间与单价降幅，测算最大批量采购折扣率。
- **跨境毛利与单位经济测算**：精准推导采购出厂价、国内到仓+跨境小包落地成本、独立站扣除支付手续费后的净收入、单件毛利与保本广告投产比 (Break-Even ROAS)。
- **7 项核心风险触发器排查**：
  1. `LOW_RETURN_RATE`: 回头率 < 15% 行业警戒线
  2. `NO_RETURN_INSURANCE`: 缺乏退换货/破损包赔等买家保障
  3. `HIGH_MOQ`: 起订量 > 50 件，不利于初期轻量测款
  4. `ZERO_SALES`: 近 30 天无有效动销
  5. `NO_FACTORY_VERIFICATION`: 非源头超级工厂或实力商家，防范二道贩子
  6. `PRICE_TIER_MISSING`: 缺失批发阶梯折让价格
  7. `WIDE_PRICE_SPAN`: 最高/最低单价跨度 > 3.0x，拦截低价引流陷阱
- **操作员行动决议**：输出 `RECOMMENDED`、`CONDITIONAL` 或 `HIGH_RISK` 并附带可执行中文处置建议。

### 6. 离线真理库检索与审计
```bash
# 查看本地库统计信息
1688-ops db stats

# 查看本地离线商品列表（支持按销量降序）
1688-ops db list --limit 20 --sort sales

# 关键词过滤本地离线商品
1688-ops db list --keyword "椅子"

# 审计单个商品的原始抓取凭据与派生计算过程
1688-ops inspect 1024786474053

# 查看离线采购车记录
1688-ops db cart

# 查看离线采购订单记录
1688-ops db orders
```

### 7. 可观测性对账器
```bash
# 1. 能读：运行环境、库容量与适配器同步状态检查
1688-ops diagnose

# 2. 能试：纯函数解析器样本即时验算
1688-ops diagnose --test-parser

# 3. 能调：热同步适配器源码到运行区并重启桥接
1688-ops diagnose --reconcile

# 4. 手动同步适配器并校验 SHA-256
1688-ops install-adapters
```

## 测试与质量验证

项目包含纯函数解析器、SQLite 单一事实来源、适配器契约、诊断器及智能决策推理引擎五大测试套件，共 36 项自动化测试：

```bash
npm test
```

测试覆盖范围：
1. `tests/unit_parsers.test.js`：测试价格范围、单价提取、2026 年份过滤、销量万级换算、回头率百分比提取、起订量等边界用例 (16 项)。
2. `tests/db.test.js`：测试模式初始化、冲突更新去重、按销量/回头率排序检索、搜索历史与审计日志 (5 项)。
3. `tests/adapter_contract.test.js`：双向比对源码区与运行区的 10 个适配器文件，杜绝代码漂移 (3 项)。
4. `tests/diagnose.test.js`：测试能读、能试、能调对账逻辑 (3 项)。
5. `tests/reasoner.test.js`：测试供应商量化评分、阶梯降价分解、跨境毛利模型及 7 项风控排查 (9 项)。
