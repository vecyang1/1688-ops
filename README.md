# 1688 批发采购与数据对账系统 (`1688-ops`)

基于浏览器已认证原生会话的 1688（阿里巴巴中国站）货源检索、拍立淘搜款、阶梯批发价提取、采购车同步、订单拉取与离线数据真理库工具套件。

## 核心设计准则

1. **合力造轮子，严禁碎片化**：
   - 适配器唯一源码归属：`~/Documents/A-coding/opencli-fork/clis/1688`。
   - 运行态热部署路径：`~/.opencli/clis/1688`。
   - 严禁在调用方散落临时抓取脚本；所有改动通过 `adapter_contract.test.js` 执行哈希一致性校验。
2. **单一事实来源 (Single Source of Truth, SSOT)**：
   - 本地 SQLite (`data/1688_ops.db`) 作为终态真理库。
   - 所有在线抓取的商品、采购车与订单数据统一收敛入库，离线可秒级查询与多维排序。
3. **单向数据流 (Unidirectional Data Flow)**：
   - 读流向：数据库 -> 数据访问层 -> CLI 终端展示。
   - 写流向：浏览器抓取 -> 纯函数清洗与派生计算 -> 写入数据库 -> 重新查询渲染。
4. **能派生不另存**：
   - 销量整数与回头率百分比在解析阶段由原始展示文本即时派生，原始凭据与计算结果并存。
5. **可观测性与对账器优先 (Diagnostic-First)**：
   - “能读”：读取当前环境配置、数据库统计与 10 个适配器的 SHA-256 同步状态。
   - “能试”：使用真实生产解析函数对脏数据样本（包含年份混淆、多重促销文本等）进行白盒推导对账。
   - “能调”：支持从适配器源码一键热同步至 OpenCLI 运行区。

## 常用命令说明

### 1. 登录态与环境诊断
```bash
# 检查 1688 登录态与操作者身份
1688-ops doctor

# 输出当前登录账号结构化数据 (JSON)
1688-ops whoami
```

### 2. 货源检索与以图搜款
```bash
# 关键词检索货源并自动入库
1688-ops search "折叠椅" --limit 20

# 纯在线查询不写入离线库
1688-ops search "户外帐篷" --limit 10 --no-sync

# 拍立淘以图搜款
1688-ops image-search /path/to/sample.jpg --limit 10
```

### 3. 商品详情与店铺查询
```bash
# 抓取指定商品详细信息（含多图清单、起订量、服务保障）
1688-ops item 1024786474053

# 查询供应商店铺档案与经营资质
1688-ops store shop751a009v46r94
```

### 4. 采购车与采购订单
```bash
# 拉取当前买家采购车并同步入库
1688-ops cart

# 拉取采购订单流水并同步入库
1688-ops orders
```

### 5. 离线真理库检索与审计
```bash
# 查看本地库统计信息
1688-ops db stats

# 查看本地离线商品列表（支持按销量降序）
1688-ops db list --limit 20 --sort sales

# 关键词过滤本地离线商品
1688-ops db list --keyword "椅子"

# 审计单个商品的原始抓取凭据与派生计算过程
1688-ops inspect 1024786474053

# 查看离线采购车记录
1688-ops db cart

# 查看离线采购订单记录
1688-ops db orders
```

### 6. 可观测性对账器
```bash
# 1. 能读：运行环境、库容量与适配器同步状态检查
1688-ops diagnose

# 2. 能试：纯函数解析器样本即时验算
1688-ops diagnose --test-parser

# 3. 能调：热同步适配器源码到运行区并重启桥接
1688-ops diagnose --reconcile
```

## 测试与质量验证

项目包含纯函数解析器、SQLite 单一事实来源、适配器契约与诊断器四大测试套件：

```bash
npm test
```

测试覆盖范围：
1. `tests/unit_parsers.test.js`：测试价格范围、单价提取、2026 年份过滤、销量万级换算、回头率百分比提取、起订量等边界用例。
2. `tests/db.test.js`：测试模式初始化、冲突更新去重、按销量/回头率排序检索、搜索历史与审计日志。
3. `tests/adapter_contract.test.js`：双向比对源码区与运行区的 10 个适配器文件，杜绝代码漂移。
4. `tests/diagnose.test.js`：测试能读、能试、能调逻辑。
